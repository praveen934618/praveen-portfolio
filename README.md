# Praveen Seelam Portfolio

Responsive freelance portfolio built with:
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Run
Open `index.html` in a browser.

## Before publishing
1. Add GitHub/live-demo links to project cards when available.
2. Add a resume download button after placing your final resume in this folder.
3. Replace or expand project descriptions as your portfolio grows.
4. Deploy with GitHub Pages, Netlify, or another static hosting service.
